# Медицинская информационная система (МИС)

Пациенты, врачи, приёмы, назначения, анализы, аудит доступа.
Стек: FastAPI + PostgreSQL + Docker.

## Возможности
- Картотека пациентов
- Расписание врачей
- Приёмы и назначения
- История болезней
- Аудит доступа (соответствие требованиям ИБ)
- Аналитика: нагрузка врачей, статистика диагнозов
